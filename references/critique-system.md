# Multi-Screen Critique

Use for multiple principal screens in a flow or app. Compare available renders at comparable scales; inspect them sequentially or side by side, whichever is practical. An existing montage can help, but creating one is optional and should not require building special tooling. Inspect individual views and relevant scroll positions as needed; a cropped montage alone cannot establish that a full screen is usable. If actual renders cannot be inspected, report visual review as unverified.

- Compare each screen's job, focal point, reading path, and grouping. Distinguish a coherent system from repetitive layouts that ignore different tasks; do not force variety when consistency helps.
- Check repeated surfaces, emphasis, typography, icons, navigation, and the meaning of persistent actions across screens. A reduced-size or grayscale montage can help diagnose a repeated silhouette but is optional.
- Trace shared values, labels, units, selections, and states; report contradictions and unsupported assumptions. Use [product integrity](product-integrity.md) to verify important actions when interaction evidence is available.
- Identify product-specific visual decisions and distinguish them from generic decoration. Report evidence and the most consequential change.

For redesign, compare matching before-and-after captures using [redesign review](redesign-review.md). For critique-only requests, recommend changes without modifying the artifact.
